# Text Memify

## About This App
Text Memify is a small utility app for macOS that allows you to quickly "memify" text, eliminating the human error when trying to type them out!

![Text Memify Header Screenshot](https://raw.githubusercontent.com/Harry-Dinh/Text-Memify/refs/heads/text-memify/Assets/Text%20Memify%20Sample%20Screenshot.png)

This app was written 100% in Swift, with its user interface written in SwiftUI. In addition to a native macOS look and feel, it also follows the guidelines outlined in the Apple Human Interface Guidelines. Tiny details such as keyboard shortcuts are fully implemented.

## Supported Meme Formats
- Wide (lowercased): `w i d e`
- Wide (uppercased): `W I D E`
- Reversed: `desreveR`
- Up and Down: `uP aNd DoWn`
